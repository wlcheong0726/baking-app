# Baking App (Backend)

This is a Spring Boot REST API for managing blog posts in a baking-themed application.
This backend powers the [baking-app-web-ui](https://github.com/wlcheong0726/baking-app-web-ui.git) frontend.

---

## Features
- Create, Read, Update, Delete (CRUD) blog posts
- Input validation with 'javax.validation'
- In-memory H2 database (for dev/testing)
- RESTful endpoints (`/api/blogs`)
- JSON responses with error handling

---

## Tech Stack
- Java 21
- Maven 3.9.1

### Run Locally
```bash
# Clone the repo
git clone https://github.com/YOUR_GITHUB_USERNAME/baking-app.git
cd baking-app

# Build and run
mvn spring-boot:run
```
